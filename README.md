## Featured Project

### CIT 学食メニュー in LINE

千葉工業大学の学食メニューと混雑状況を、LINEから手軽に確認できる非公式サービス。

- 3つの食堂のメニューとライブカメラ画像を、LINE上で案内
- 学食メニューのPDFを画像へ変換し、トーク画面に表示
- スケジュール実行と変更検知により、メニューの更新を自動化
- Cloudflare Workers / KV を活用したサーバーレス構成
